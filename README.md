# printer-tools
## Printer sales tools

Mobile-friendly tools for printer and toner sales. Static HTML, no build step. Deploy the repo root to Cloudflare Pages.

- `index.html` – home page
- `finder.html` – Printer Finder (Brother, Lexmark, HP, Xerox, Canon, Epson)
- `speed.html` – Print Speed Compare
- `toner.html` – Toner Cost Compare
- `data/` – source spreadsheets (Canadian models, supplies, prices)

Prices are CAD from brand and retailer sites, collected November 2026.
